# ADR-0001: Use Go for backend services

- **Status:** Accepted
- **Date:** 2026-11-26

## Context
Nexora demonstrates backend engineering and distributed-systems skills through independently deployable services. The implementation needs practical concurrency support and a straightforward deployment model.

## Decision
Use Go for backend services, workers and supporting command-line programs.

## Consequences
- Service code, tests and tooling use the Go toolchain.
- Each independently built service owns its module boundary unless repository experience justifies a different strategy.
- Keep domain logic idiomatic and simple.
- Gin is for HTTP services; gRPC servers, Kafka consumers and workers use appropriate libraries and runtime patterns.
